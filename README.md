# Northstar Safe — Projeto Escolar

Este é um **projeto educacional** desenvolvido como parte de atividades escolares. O objetivo é demonstrar competências em desenvolvimento web, design UI/UX e boas práticas de segurança em aplicações frontend.

## 📚 Contexto educacional

O projeto foi criado para:
- Aplicar conhecimentos de HTML5, CSS3 e JavaScript vanilla
- Praticar design responsivo e acessibilidade
- Implementar padrões modernos de interface (inspirados em SaaS)
- Demonstrar segurança básica em aplicações web (sanitização de entrada, validação de formulários)
- Organizar código em estrutura profissional

## 🎨 Características

- **Design moderno** com paleta de cores profissional
- **Interface responsiva** para desktop, tablet e mobile
- **Autenticação simulada** com armazenamento em SessionStorage
- **Fluxos de emergência** com links rápidos e geolocalização
- **Feedback visual** com toasts, loaders e animações suaves
- **Acessibilidade** com ARIA labels, navegação por teclado e contraste adequado

## 🔐 Notas de segurança

Este é um **projeto educacional** e não possui backend real. Os dados são armazenados apenas em `sessionStorage` do navegador.

Em uma aplicação real, seria necessário:
- Servidor backend com autenticação segura (OAuth, JWT)
- Banco de dados protegido
- HTTPS obrigatório
- Rate limiting e proteção contra ataques
- Conformidade com LGPD/GDPR
